# Propeller Calculator — BEM + NACA 4412

Автономный инженерный инструмент для расчёта воздушного винта и генерации
3D-модели в формате STEP для печати на FDM-принтере.

## Состав

| Файл | Назначение |
|---|---|
| `propeller_calculator.html` | Автономный калькулятор: BEM-решатель, 13 проверок, 5 графиков. Открывается в браузере, работает без интернета и без зависимостей. |
| `propeller_step_gen.py` | Генератор твердотельной STEP-модели по экспортированному JSON. Требует CadQuery. |

## Физическая модель

Расчёт ведётся по теории элемента лопасти с балансом импульса (BEM) для режима
осевого полёта, по 24 радиальным сечениям, с поправкой Прандтля на концевые потери.

Для каждого сечения итерационно решаются коэффициенты индукции `a` (осевой)
и `b` (окружной) до сходимости по невязке 1e-8:

```
phi   = atan2( V0*(1+a), omega*r*(1-b) )
alpha = beta - phi
dT    = 0.5*B*rho*W^2 * (CL*cos(phi) - CD*sin(phi)) * c * dr
dQ    = 0.5*B*rho*W^2 * (CL*sin(phi) + CD*cos(phi)) * c * r * dr
```

Связь с импульсной теорией для сверки тяги и скорости потока за винтом:

```
T      = 2*rho*A*(V0 + vi)*vi
V_wake = V0 + 2*vi
```

### Профиль NACA 4412

Генерируется аналитически (4-значная серия, косинусное сгущение точек к носку).
Проверенные характеристики геометрии замкнутого контура:

- максимальная толщина — 12.0% хорды
- площадь сечения — 0.08197 * c^2
- момент инерции — 1.5493e-4 * c^4

Последние две величины используются напрямую в расчёте напряжений и прогиба.

Поляра: `CL = 0.4 + 0.11*alpha[град]`, модель срыва при `|alpha| > 14`,
минимум CD и максимум CL/CD около `alpha = 5` градусов — это значение стоит
по умолчанию как проектный угол атаки.

## Исходные данные

Диаметр винта, обороты, число лопастей, скорость набегающего потока,
желаемая тяга, диаметр оси, диаметр бобышки, толщина у основания.

Тяга и скорость потока за винтом вместе задают переопределённую систему,
поэтому ведущей величиной принята тяга из BEM, а скорость за винтом выводится
через импульсную теорию и показывается как проверка. Невязка по целевой тяге
выводится в процентах. Кнопка подбора шага выполняет бисекцию по углу
установки до попадания в целевую тягу.

## Граничные условия (13 проверок)

Шаг винта по сечениям, ширина лопасти, толщина у основания и на 10% / 90%
длины, жёсткость (прогиб конца), прочность материала, скорость конца лопасти,
отношение к скорости звука, тяга, скорость потока за винтом, заполнение диска,
число сечений в срыве, сходимость решателя.

Прочность: растяжение от центробежной силы `sigma_c = Fc/A0`, где
`Fc = integral( rho_mat * A(r) * omega^2 * r * dr )`, плюс изгиб от
аэродинамической нагрузки. Центробежный разрыв у корня — основной режим
отказа печатного винта.

## Материалы FDM

Расчёт ведётся раздельно по XY- и Z-прочности в зависимости от ориентации печати.

| Материал | sigma XY, МПа | sigma Z, МПа | E, МПа | rho, кг/м3 |
|---|---|---|---|---|
| PETG | 50 | 26 | 2000 | 1270 |
| PETG-CF | 55 | 22 | 5500 | 1300 |
| PA-CF | 85 | 40 | 6500 | 1180 |
| ASA-CF | 60 | 28 | 5000 | 1150 |

Важный нюанс: углеволокно повышает модуль упругости PETG примерно втрое,
но снижает межслойную прочность — волокно увеличивает вязкость расплава
и мешает диффузии полимера между слоями. Отжиг PETG-CF при 120 C частично
это компенсирует. Для нагруженного винта предпочтителен PA-CF.

## Графики

1. Тяга от оборотов (с наложенным числом Маха на второй оси)
2. Тяга от мощности на валу (с кривой КПД)
3. Тяга от скорости набегающего потока (до режима авторотации)
4. Распределение хорды, толщины и углов по радиусу
5. Сечения NACA 4412 на 0.1R / 0.5R / 0.9R плюс гистограмма распределения тяги

Все кривые пересчитываются полным BEM-решателем в каждой точке, без аппроксимаций.

## Использование

### Калькулятор

Открыть `propeller_calculator.html` в браузере. Задать параметры, нажать
«Рассчитать». Экспорт: JSON (для генератора STEP) и CSV (таблица сечений).

### Генератор STEP

```bash
pip install cadquery

python propeller_step_gen.py propeller_params.json -o vint.step --stl vint.stl
python propeller_step_gen.py --demo        # проверка со встроенными параметрами
```

Ключи: `--fillet` (радиус скругления у корня), `--pitch-axis` (положение оси
поворота сечения по хорде, по умолчанию 0.30), `--no-tip-round`,
`--tolerance` (точность STL).

Модель строится лофтом по сечениям через `Solid.makeLoft(ruled=False)` —
гладкие B-spline поверхности. Корневое сечение продлевается внутрь втулки
для надёжного булева объединения; конец сужается для скругления.

## Контрольный пример

D = 280 мм, 3 лопасти, V0 = 12 м/с, втулка 50 мм, ось 6 мм, PETG, печать плашмя:

| Обороты | Тяга, кг | Мощность, Вт | Маха | КПД |
|---|---|---|---|---|
| 4000 | 0.204 | 29.1 | 0.175 | 0.823 |
| 5000 | 0.453 | 66.6 | 0.217 | 0.800 |
| 6000 | 0.782 | 121.7 | 0.259 | 0.756 |
| 7000 | 1.194 | 197.1 | 0.301 | 0.713 |

Решатель сходится за 37 итераций, углы атаки держатся 4.6-5.0 градусов
по всему радиусу.

## Печать

- ориентация: лопасть на ребро или под 45 градусов, не плашмя — иначе
  центробежная нагрузка идёт поперёк слоёв
- 100% заполнение либо 6+ периметров, слой 0.12-0.16 мм
- балансировка обязательна перед раскруткой на полные обороты

## Ограничения

Реалистичный потолок для FDM-винта — порядка 3000-5000 об/мин при диаметре
200-300 мм. Выше начинается зона, где нужна литая или фрезерованная лопасть.

Поляра профиля задана аналитической аппроксимацией, а не таблицей XFOIL —
для финального проекта характеристики стоит уточнить под фактическое число
Рейнольдса. Модель срыва упрощённая, за пределами линейного участка точность
падает. Скругление у корня на сложной лофт-геометрии иногда не проходит
в ядре OpenCascade; скрипт это перехватывает и сообщает.
